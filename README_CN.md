# Chromium 多容器扩展

一个用于管理 Chromium 系浏览器（Chrome、Edge、Brave 等）中多个独立容器/标签页的浏览器扩展。

![扩展主视图](extentionpic.jpg)
*扩展主视图*

## 安装（开发者模式）

由于该扩展尚未发布到网上应用商店，您需要手动加载它。

1. **打开扩展程序页面**  
   前往 `chrome://extensions`（在 Microsoft Edge 中为 `edge://extensions`）。

2. **启用开发者模式**  
   打开右上角的**开发者模式**开关。  
   ![开发者模式开关](help01.jpg)

3. **点击“加载已解压的扩展程序”**  
   启用开发者模式后，会出现一个新按钮。点击**加载已解压的扩展程序**。  
   ![加载已解压的扩展程序按钮](help02.jpg)

4. **选择扩展文件夹**  
   在文件对话框中，导航到包含扩展文件的文件夹（确保 `manifest.json` 在其中）。选择该文件夹并点击**选择文件夹**（或**打开**）。  
   ![选择文件夹](help03.jpg)

扩展图标应出现在浏览器的工具栏中。现在您可以使用它了。

## 功能特性

- 为不同的浏览场景管理独立的容器
- 快速切换和分组标签页
- 容器标签页自动归组，浏览器顶部显示容器名称和颜色；同一窗口中同一容器共用一个组，不同窗口分别分组
- 弹出窗口和侧边栏顶部可切换深色／浅色主题，选择自动保存并在两个界面间同步
- 轻量级，基于 Chromium 的多进程架构

更新扩展后，在扩展程序页面点击“重新加载”，现有容器标签页会自动恢复分组。修改容器名称或颜色时，已有分组同步更新。

容器页面先在空白标签页完成隔离初始化，再导航到网站。隔离启用失败时会返回错误，不会继续打开未隔离的网站。更新扩展后，请刷新已有网站标签页，使新的页面存储隔离脚本生效；已经串用的登录态需要在各容器分别重新登录。

网页通过 `window.open(网址)`、`target="_blank"` 链接、Ctrl 点击或中键打开 HTTP(S) 新标签页时，先保持空白页，继承来源容器并初始化隔离，然后加载目标网址并加入相同分组。同源不同路径（例如 `/asset/` 与 `/aiassistant/`）共享该容器的 localStorage；Cookie 仍遵守其 Domain、Path 等作用范围。此流程尚未覆盖右键菜单原生打开、表单新窗口提交，以及先 `window.open()` 空白窗口再由网页直接修改其 location 的写法。

开发验证：安装 Node.js 后运行 `node --test tests/tab-groups.test.cjs tests/isolation.test.cjs`，检查分组、容器管理、请求与响应 Cookie 隔离。使用 Node.js 22+，将 `CHROMIUM_EXECUTABLE` 环境变量指向支持加载未打包扩展的 Chromium 可执行文件，再运行 `node tests/browser-isolation.cjs`，可在独立临时配置和本地模拟站点中验证双账号登录、Cookie、页面存储、上述四种新标签页打开方式的首次请求及首次脚本、同源跨路径导航、页面刷新和扩展重载。测试不使用日常浏览器配置。
